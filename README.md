# Ruben

## סידור הגלריה של הנייד (Samsung Galaxy A73)

הסקריפט `organize_gallery.py` ממיין תמונות וסרטונים לתיקיות לפי סוג ותאריך, ומעביר כפילויות לתיקייה נפרדת. **הוא לא מוחק שום דבר.** כברירת מחדל הוא רק מציג תצוגה מקדימה.

### 1. העברת התמונות למחשב
1. מחברים את הטלפון למחשב בכבל USB.
2. בטלפון, בהתראה שקופצת, בוחרים **"העברת קבצים"**.
3. במחשב פותחים את הטלפון ומעתיקים לתיקייה אחת, למשל `C:\Phone`, את התיקיות:
   - `DCIM` – תמונות וסרטונים מהמצלמה (`DCIM/Camera`)
   - `Pictures` – צילומי מסך (`Pictures/Screenshots`) והקלטות מסך
   - `Android/media/com.whatsapp/WhatsApp/Media` – תמונות וסרטונים מוואטסאפ

### 2. התקנה
- להתקין Python 3 מ-https://www.python.org (ב-Windows לסמן "Add Python to PATH").
- רשות, אבל מומלץ, כדי לקרוא את תאריך הצילום מתוך התמונה:
  ```
  pip install pillow pillow-heif
  ```

### 3. הרצה
תצוגה מקדימה (לא משנה כלום):
```
python organize_gallery.py C:\Phone C:\Gallery
```
אם התוצאה נראית טוב, מעתיקים בפועל:
```
python organize_gallery.py C:\Phone C:\Gallery --apply
```
(`--move` יעביר במקום להעתיק. `--keep-duplicates` לא יפריד כפילויות.)

### התוצאה
```
Gallery/
  Photos/2024/2024-03/...
  Videos/2024/2024-03/...
  Screenshots/2024/...
  Screen recordings/2024/...
  WhatsApp/Images/2024/...  WhatsApp/Videos/2024/...
  Duplicates/...   ← עותקים זהים לגמרי של קובץ שכבר מוין: לבדוק ולמחוק ידנית
```

התאריך נלקח לפי הסדר הזה: מתוך נתוני התמונה (EXIF), משם הקובץ של סמסונג או וואטסאפ (`20240315_142233.jpg`, `IMG-20240315-WA0012.jpg`), ואם אין, מתאריך שינוי הקובץ.

### 4. החזרה לטלפון (רשות)
מעתיקים את תיקיית `Gallery` חזרה לטלפון, למשל ל-`Pictures/Gallery`. הגלריה של סמסונג תציג כל תיקייה כאלבום. רק אחרי שבדקתם שהכול הגיע, מוחקים את המקור מהטלפון כדי לפנות מקום.
